# RK3566 7 寸全屏与可配置地址设计

## 意图

让跌倒检测服务端在 RK3566 的 1024×600 七寸屏上完整显示，并允许现场人员直接修改网络地址而无需重编译。

## 目标

- 主窗口启动即全屏，适配 1024×600，不出现纵向裁切。
- 顶部常驻配置栏包含监听 IP、端口、RTSP 地址与“应用配置”按钮。
- 默认值分别为 `192.168.10.3`、`9000`、`rtsp://192.168.10.2:8554/BackChannelTest`。
- 应用新配置时停止当前 TCP 监听与视频播放，以新参数启动；不合法 IP、端口或 URL 显示错误并保留原生效配置。
- 缩小视频、状态、人数与日志区域间距，保证所有内容可见。

## 非目标

- 不保存配置到磁盘；重启后恢复默认值。
- 不修改 K230 TCP 协议或 RTSP 解码逻辑。

## 方案比较

1. 顶部常驻配置栏（选定）：修改地址最快，代价是占用约 70 像素高度。
2. 配置弹窗：视频区域略大，但现场操作多一步。

## 实现

- 用 `QLineEdit` 和 `QSpinBox` 替换硬编码端点的唯一使用入口；生效值保存在 `Widget` 成员中。
- `applyConfiguration()` 先校验、停止旧连接与播放器，更新端点后重启服务与视频。
- 将窗口最大化显示为全屏，并将各分组设置紧凑最小尺寸，日志压缩为约 85 像素高度。
