# RK3566 工业上位机界面改版

## 意图

去除营销式深色卡片和“AI 仪表盘”视觉，将当前监控台改为现场值班人员熟悉的工业上位机界面。

## 目标

- 采用浅灰窗口背景、标准 Qt 分组框、表格式状态行和常规矩形按钮。
- 左侧以 RTSP 画面为主，右侧集中显示服务、客户端、最后更新时间与人数。
- 用小型圆形状态灯配合文字标识服务、连接与告警状态；告警仅使用必要的红色。
- 日志保留在底部，使用紧凑等宽字体，方便排障。

## 非目标

- 不修改 TCP 协议、RTSP 地址、人数处理逻辑或播放器实现。

## 方案

1. 深色安防风格：保留当前基调但压缩装饰，仍有较强展示感。
2. 工业上位机风格（选定）：浅色、信息密度高、标准控件优先，便于长期使用和维护。

## 实现

- 仅调整 `widget.cpp` 的布局文字、对象名和 QSS，不改变网络 API。
- 标题改为“RK3566 跌倒检测服务端”，移除“智慧”“实时视频”等营销式文案。
- 状态区使用分组框与固定标签；人数以表格行呈现，取消大号卡片数字。
- 告警使用红色状态灯和简短文本；安全状态使用绿色指示灯。
