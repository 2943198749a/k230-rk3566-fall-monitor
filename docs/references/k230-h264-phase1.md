# K230 H.264 Phase 1 Runbook

## Scope and safety

This procedure validates the experimental TCP-directory big-core ELF with
**video only**. It must never overwrite or modify `/sharefs/app/falldown_rtsp/`.
Do not start `k230_status_tcp_client` during this phase.

## Build preflight on WSL

```sh
SDK=/home/user/work/k230_sdk
APP=/home/user/work/k230-rk3566-yolo-falldown/k230

strings "$SDK/src/big/mpp/userapps/lib/libvicap.a" | grep -m1 'Nov  6 2024'
cmake -S "$APP" -B /tmp/falldown-rtsp-tcp-v3 \
  -DCMAKE_TOOLCHAIN_FILE="$APP/../cmake/Riscv64.cmake" \
  -DFALLDOWN_RTSP_TCP_BUILD_K230_APPS=ON \
  -DK230_SDK_ASSET_ROOT="$SDK"
cmake --build /tmp/falldown-rtsp-tcp-v3 --target falldown_rtsp_tcp_big.elf -j2

file /tmp/falldown-rtsp-tcp-v3/big/falldown_rtsp_tcp_big.elf
strings /tmp/falldown-rtsp-tcp-v3/big/falldown_rtsp_tcp_big.elf | grep -F 'payload type is %s'
sha256sum /tmp/falldown-rtsp-tcp-v3/big/falldown_rtsp_tcp_big.elf
```

The selected `libvicap.a` must print `Nov 6 2024`; any `Jun 14 2024` build
must be rejected. The ELF must be RISC-V. Record the printed hash below before
copying it to the board.

## Board preflight and transfer

On K230 COM6:

```sh
df -h /sharefs
ps -ef | grep '[k]230_status_tcp_client'
```

Require at least 30 MB free and no status client. Copy only to this new name:

```sh
wget -O /sharefs/app/falldown_rtsp_tcp/falldown_rtsp_tcp_big_h264_v3.elf \
  http://192.168.10.1:8001/falldown_rtsp_tcp_big_h264_v3.elf
chmod +x /sharefs/app/falldown_rtsp_tcp/falldown_rtsp_tcp_big_h264_v3.elf
sha256sum /sharefs/app/falldown_rtsp_tcp/falldown_rtsp_tcp_big_h264_v3.elf
```

The K230 hash must equal the WSL build hash. Do not replace an existing binary.

## Two-minute video validation

Stop only experimental COM7/COM6 test programs. Then use:

```sh
# COM7 (RT-Smart)
cd /sharefs/app/falldown_rtsp_tcp
./falldown_rtsp_tcp_big_h264_v3.elf yolov5n-falldown.kmodel 0.5 0.45 0

# COM6 (Linux), after COM7 prints PhyAddr: 1628c000
cd /sharefs/app/falldown_rtsp_tcp
./rtspServer -p 1628c000 -t h264

# RK3566
ffplay -rtsp_transport tcp rtsp://192.168.10.2:8554/BackChannelTest
```

COM7 must print `payload type is H264`, `PhyAddr: 1628c000`, and no VICP,
sensor, or ISP failure. Keep FFplay running for at least two minutes; it must
report a concrete H.264 resolution and show normal frames without decode errors.

## Rollback

If the new experiment is not normal, stop only its COM7/COM6 processes and
return to the untouched known-good deployment:

```sh
# COM7
cd /sharefs/app/falldown_rtsp
./falldown_rtsp_big.elf yolov5n-falldown.kmodel 0.5 0.45 0

# COM6
cd /sharefs/app/falldown_rtsp
./rtspServer -p 1628c000 -t h264
```
